About

このサイトについて

日常業務で参照頻度の高い情報を、静的サイトとして整理した個人メモです。検索性、更新しやすさ、スマホ片手操作を優先しています。

位置づけ

  • 業務補助用メモであり、診療判断や医療行為を断定する用途ではありません。
  • 最終確認は添付文書、最新の公式資料、施設ルールで行う前提です。
  • 患者個人情報や店舗固有の秘匿情報は扱わない想定です。

設計方針

  • GitHub Pages にそのまま配置できるよう、ビルド不要の静的構成にしています。
  • データは `data/` の JSON に分離し、HTML 側は表示に専念させています。
  • 表記ゆれ対応のため、各データに `aliases` や `note` を持たせています。
  • 業務チェックリストは `localStorage` に保存し、日付単位で管理します。

利用時の注意

  • 小児用量は必ず体重、年齢、適応、剤形を再確認してください。
  • 加算や調剤管理の算定要件は改定や施設運用で差が出るため、最新の算定資料を優先してください。
  • 本サイトの内容は個人メモベースのため、必要に応じて自分用に追記・修正して使う前提です。
